#Requirements

The requirements for the calculator program to work as intended is listed below.

1. Be able to add 2 numbers.
2. Be able to divide 2 numbers
3. Be able to multiply 2 numbers.
4. Be able to subtract 2 numbers.
5. Display the prompt, and display the result of your operations.
6. If there is a number divided by 0, display "Error" and go back to the prompt.
